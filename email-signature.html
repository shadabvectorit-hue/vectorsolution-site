How to install it

Outlook on the web / Microsoft 365 (this is where your shadab@vectorsolution.it mailbox lives)

  1. Click Copy signature above.
  2. Open Outlook on the web → the gear icon (top right) → Settings.
  3. Go to Mail → Compose and reply.
  4. Under Email signature, name it "Full", click into the editing box and paste with Ctrl + V.
  5. Add a second signature named "Reply" and paste the short one into it.
  6. Below the box, set For new messages to Full and For replies/forwards to Reply. Save.

Outlook desktop (Windows)

  1. Copy the signature, then in Outlook go to File → Options → Mail → Signatures.
  2. New, give it a name, paste into the edit box, and set the new-messages and replies dropdowns on the right.

Gmail

  1. Copy the signature, then open Gmail → gear icon → See all settings.
  2. Scroll to Signature → Create new → paste into the box.
  3. Set the defaults for new mail and replies underneath, then Save Changes at the bottom of the page.

Two things worth knowing.
The logo is loaded from vectorsolution.it rather than attached to each email — that keeps your messages small and stops the logo showing up as a paperclip attachment on every reply. Some recipients block remote images by default, so the signature is built to read perfectly well even if the logo never loads.

Don't add a long legal disclaimer unless a client contract requires one. On a two-line reply it reads as corporate filler, and it makes threads harder to follow on a phone — which is how most of your Pakistani clients will read them.
